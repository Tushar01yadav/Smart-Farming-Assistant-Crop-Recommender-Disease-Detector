# 🌾 Smart Farming Assistant 🌿  
### Crop Recommender System + Crop Disease Predictor using CNN 🌱🧠  

Welcome to the **Smart Farming Assistant** — an AI-powered web app that helps farmers make data-driven decisions! This system recommends the most suitable crop based on environmental conditions and detects plant diseases using image classification (CNN).  

---

## 🔥 Features

✅ **Crop Recommendation System**  
✅ **CNN-based Crop Disease Detection**  
✅ User-friendly **Streamlit** interface  
✅ Real-time predictions 🌐  
✅ Supports multiple crops & diseases  
✅ Deployed with Hugging Face & GitHub  

---

## 🎯 How It Works

### 📌 Crop Recommender
You input:
- Soil Type 🌍
- Temperature 🌡️
- Humidity 💧
- pH Level 🧪
- Rainfall 🌧️

📢 The model suggests the **best-suited crop** based on trained machine learning algorithms.

---

### 📌 Crop Disease Predictor
You upload A **leaf image** 
📢 The CNN model detects the **type of disease** or **confirms plant health**.
